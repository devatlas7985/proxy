## 高价不等于专线

月付处于较高价位，只说明运营方可能有更多成本空间，不证明使用 IPLC、IEPL 或其他专线。线路类型需要官方技术说明、路由特征和跨时段表现共同支持；“专线机场”“企业级线路”等营销词本身证据很弱。

更可复查的做法是固定设备、入口、目标地区和时段，连续记录延迟中位数、抖动、丢包与连接失败数。若页面宣称专线而晚高峰大幅波动，应保留原始结果，不用最高速度掩盖。

## 套餐证据表要写哪些字段

至少记录套餐名称、一次实付、有效月份、每期流量、倍率、设备限制、可用客户端、退款范围和续费价格。页面写“¥25/月”时，还要确认它是真月付，还是年付总价除以十二。

套餐之间如果只是流量不同，应把线路权限是否相同写清；若高阶套餐包含独立入口或低倍率节点，也要逐项列出，不能用“更稳”概括。优惠码须在结算页复现并标注截止时间。

## 线路、解锁和可用性是三张表

线路表记录入口、出口、路由与倍率；解锁表记录 Netflix、Disney+、ChatGPT 等目标在具体节点上的结果；可用性表记录连接成功率和持续时间。三者相关但不能互相代替。

例如某节点能打开流媒体，只能说明测试当时的出口身份满足目标规则，不能说明速度、长期可用或所有节点都支持。测试结果要保留失败样本、账号地区和时间，避免给出“全解锁”这类过度概括。

## 一套可复查的核验流程

1. **身份：**保存完整域名、公告入口、订单系统和付款主体，检查四者是否能互相指向；
2. **报价：**记录抓取日期、一次实付、周期、流量、倍率、续费与退款，不只抄月均价；
3. **软件：**从已核实帮助页或上游项目下载，写明系统、架构、版本、签名和权限；
4. **测试：**固定设备、网络、客户端、节点和时段，保留成功次数与总次数；
5. **复盘：**把事实、服务方标称、第三方说法、主观体验和未知项分栏；
6. **更新：**域名、套餐、客户端或状态变化时追加新行，保留旧快照和证据日期。

这套流程不会保证任何服务未来可用，但能减少把同名页面当官网、把年付折算当月付、把单次峰值当稳定或把推广短链当品牌认证的错误。
